About This Project

Project details and the team behind Smart Traffic Monitor.

Cloud-Based Predictive Analytics for Real-Time Traffic Monitoring

Smart Traffic Monitor is an academic project that demonstrates how cloud-based predictive analytics can be used to monitor city traffic. Traffic readings (speed and vehicle count) are simulated by a Python program and stored in Firebase Realtime Database. A Random Forest model, served by a Flask API, predicts congestion levels, and the results are shown on an interactive map and charts. All traffic data is simulated.

What it does
  • Monitors 6 major roads in Hyderabad and colour-codes congestion (green / yellow / red).
  • Generates new speed and vehicle-count data every 5 seconds using a traffic model.
  • Models rush-hour peaks at 8–10 AM and 6–8 PM when roads get busiest.
  • Predicts the current congestion level for any selected road.
  • Shows a 24-hour speed trend chart so patterns across the day are easy to read.
Tech Stack

HTML, CSS and JavaScript · Leaflet.js (maps) · Chart.js (charts) · Python Flask (API) · scikit-learn Random Forest (prediction) · Firebase Realtime Database (cloud storage).
